# Лабораторна робота 3. Обробка тексту підручника з програмування (Haskell)

**Варіант 16.** У деякому реченні тексту слова заданої довжини замінити вказаним
підрядком, довжина якого може не збігатися з довжиною слова.

Програма читає текст підручника з файлу, моделює його власними типами
(символ, слово, розділовий знак, речення, текст), у всіх виведених текстах
замінює табуляції та послідовності пробілів одним пробілом і виконує заміну
у вибраному реченні.

## Вхідні дані

| Параметр | Опція | Опис |
|----------|-------|------|
| файл | позиційний аргумент | текст у кодуванні UTF-8 (кирилиця, латиниця) |
| номер речення | `-s`, `--sentence` | нумерація з 1 |
| довжина слів | `-l`, `--length` | ціле число ≥ 1 |
| підрядок-заміна | `-r`, `--replace` | може бути порожнім (`--replace=`) |

Параметри, яких немає в командному рядку, програма запитує інтерактивно.

## Модель даних (`src/Textbook/Types.hs`)

```haskell
newtype Symbol = Symbol Char                       -- символ
newtype Word   = Word [Symbol]                     -- слово
data PunctuationKind = Terminal | Opening | Closing | Quote | Inner
data Punctuation = Punctuation PunctuationKind Symbol   -- розділовий знак
data Token    = TWord Word | TPunct Punctuation | TSpace
newtype Sentence = Sentence [Token]                -- речення
newtype Document = Document [Sentence]             -- текст
```

Модулі:

| Модуль | Призначення |
|--------|-------------|
| `Textbook.Types` | типи `Symbol`, `Word`, `Punctuation`, `Token`, `Sentence`, `Document` |
| `Textbook.Normalize` | нормалізація пробілів |
| `Textbook.Parser` | токенізація і поділ на речення |
| `Textbook.Replace` | варіант 16: заміна слів заданої довжини, помилки |
| `Textbook.Render` | перетворення моделі назад у текст |
| `Textbook.CLI` | розбір аргументів командного рядка |
| `app/Main.hs` | введення/виведення, UTF-8, інтерактивні запити |

## Правила

### Пробіли

Кожна послідовність пробільних символів (пробіли, табуляції, переноси рядків,
нерозривний пробіл) стає **одним пробілом**; пробіли на краях видаляються.
Речення в результаті розділяються одним пробілом, абзаци зливаються.

### Слово

Слово — послідовність літер (кирилиця, латиниця та інші), цифр і `_`.
Усередині слова допускаються:

- апостроф `'`, `’`, `ʼ` між літерами/цифрами (`обов'язково`, `м’яч`);
- дефіс `-` між літерами/цифрами (`по-перше`);
- `.` або `,` між цифрами (`3.14`, `1,5`).

Довжина слова — кількість його символів, включно з апострофом, дефісом і
десятковою крапкою (`м'яч` має довжину 4, `3.14` — 4). Усе інше (кома, тире,
дужки, лапки, `+`, `=` тощо) — розділові знаки, вони не є словами й не
замінюються.

### Кінець речення

Речення завершує серія знаків `. ! ? …` (разом із закривальними дужками й
лапками одразу після неї), за якою йде пробіл або кінець тексту. Крапка **не**
завершує речення, якщо:

- немає пробілу після неї (`3.14`, `Data.List`);
- перед нею скорочення зі списку (`напр.`, `див.`, `рис.`, `табл.`, `проф.`,
  `Dr.`, `Fig.` та ін.) або одна велика літера (ініціал `І. Петренко`);
- після крапки чи трикрапки наступне слово починається з малої літери
  (`і т. д. і т. п.`, `Ну... добре`).

Знаки `?` і `!` завершують речення завжди.

### Заміна

- Замінюються всі слова вибраного речення з довжиною `L`; інші речення не
  змінюються.
- Розділові знаки лишаються на своїх місцях.
- Підрядок-заміна також нормалізується (послідовності пробілів і табуляції
  стають одним пробілом, пробіли на краях відкидаються) і повторно не
  переглядається.
- Порожній підрядок видаляє слово разом з одним сусіднім пробілом, тому
  подвійних пробілів або пробілу перед знаком не виникає.
- Якщо слів потрібної довжини немає, текст не змінюється, про це повідомляється.
- Номер речення поза діапазоном `1..N`, довжина `< 1`, нечислові значення,
  порожній текст і відсутній файл дають зрозуміле повідомлення про помилку
  та код виходу 1.

Обмеження: заголовки без кінцевого знака зливаються з наступним реченням;
після видалення першого слова речення наступне слово лишається з малої літери.

## Збірка, запуск, тести

Потрібні GHC (перевірено на 9.14.1) і cabal. Зовнішніх залежностей немає
(лише `base`).

```sh
cabal build                  # збірка
cabal test                   # модульні тести
scripts/smoke.sh             # наскрізна перевірка на прикладах
cabal run textbook-word-replacer -- --help
```

Приклади запуску:

```sh
# усі параметри в командному рядку
cabal run textbook-word-replacer -- -s 2 -l 5 -r "ЯЯЯ" examples/simple.txt

# пронумерований список речень
cabal run textbook-word-replacer -- --list examples/textbook_uk.txt

# лише змінений текст
cabal run textbook-word-replacer -- --text-only -s 6 -l 5 -r "ЇЖ" examples/textbook_uk.txt

# інтерактивно (файл і параметри запитуються)
cabal run textbook-word-replacer
```

Кодування UTF-8 для введення, виведення, файлів і аргументів встановлюється
програмою незалежно від локалі.

## Приклад

Файл `examples/simple.txt`:

```
Перше речення тут. Друге речення з кількома словами! Третє: питання?
```

Заміна слів довжини 7 у реченні 2 на довший підрядок:

```
$ textbook-word-replacer -s 2 -l 7 -r "[ДУЖЕ ДОВГИЙ]" examples/simple.txt
Було:  Друге речення з кількома словами!
Стало: Друге [ДУЖЕ ДОВГИЙ] з кількома [ДУЖЕ ДОВГИЙ]!
Замінено слів: 2

Весь текст:
Перше речення тут. Друге [ДУЖЕ ДОВГИЙ] з кількома [ДУЖЕ ДОВГИЙ]! Третє: питання?
```

Порожня заміна (слова довжини 5 видаляються):

```
$ textbook-word-replacer -s 2 -l 5 --replace= examples/simple.txt
Було:  Друге речення з кількома словами!
Стало: речення з кількома словами!
Замінено слів: 1

Весь текст:
Перше речення тут. речення з кількома словами! Третє: питання?
```

Помилка:

```
$ textbook-word-replacer -s 9 -l 3 -r x examples/simple.txt
Помилка: речення з номером 9 не існує (у тексті речень: 3, допустимі номери: 1..3)
```

Файл `examples/messy.txt` містить табуляції, послідовності пробілів, порожні
рядки та CRLF; `examples/textbook_uk.txt` і `examples/textbook_en.txt` —
довші тексти з скороченнями, десятковими числами, лапками й трикрапками.
